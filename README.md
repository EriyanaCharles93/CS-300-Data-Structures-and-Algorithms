# CS-300-Data-Structures-and-Algorithms
SNHU CS 300 portfolio showcasing data structure analysis, algorithm efficiency, and a C++ course advising application.
## Portfolio Reflection

### What was the problem you were solving in the projects for this course?

In this course, I worked on projects that involved organizing, storing, and retrieving information efficiently. For Project One, I analyzed different data structures, including vectors, hash tables, and binary search trees, to determine their runtime and memory efficiency. For Project Two, I developed a C++ program for ABCU that allows academic advisors to load course information, display courses in alphanumeric order, and search for specific courses and their prerequisites.

### How did you approach the problem? Consider why data structures are important to understand.

I approached the projects by reviewing the requirements and determining which data structures would work best. I compared how vectors, hash tables, and binary search trees store and retrieve information. I learned that understanding data structures is important because they affect how efficiently a program operates. For Project Two, I used a binary search tree to organize course information and display it in order. This helped me understand how choosing the right data structure can improve a program's performance.

### How did you overcome any roadblocks you encountered while going through the activities or project?

One challenge I encountered was making sure the program correctly read the CSV files and organized the course information. I also had to understand how the binary search tree worked when inserting, searching, and displaying courses. To overcome these challenges, I reviewed my code, checked file locations, and tested the program multiple times. Breaking problems into smaller steps helped me identify errors and make corrections. Testing with valid and invalid files also helped me understand the importance of error handling.

### How has your work on this project expanded your approach to designing software and developing programs?

These projects helped me understand that software development involves more than writing code that works. I learned the importance of planning, analyzing requirements, and selecting an appropriate data structure before beginning development. Comparing runtime and memory efficiency showed me how different approaches can affect a program's performance. I now have a better understanding of why developers should consider efficiency, organization, and functionality when designing software.

### How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

My work in this course helped me improve how I organize and write code. I learned to use functions, classes, comments, and meaningful variable names to make programs easier to understand. I also learned the importance of testing different situations and handling errors to prevent unexpected results. Moving forward, I want to continue writing code that is organized, easy to update, and understandable to other developers. These projects gave me a stronger foundation in data structures and helped me become more confident in my programming skills.
